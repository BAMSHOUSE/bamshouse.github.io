ข้อมูลที่ใช้และวัตถุประสงค์

  • ชื่อ เบอร์โทร และข้อมูลรายการผู้เรียนจาก Airtable: ใช้สร้างบัญชี จับคู่บทเรียน และให้สิทธิ์เข้าเรียน
  • วันเริ่มเรียน วันสิ้นสุดคอร์ส การรับทราบ และ session: ใช้ตรวจอายุคอร์สและรักษาสถานะการเข้าใช้งาน
  • ข้อมูลร่าง เนื้อหาที่เผยแพร่ และบันทึกสถานะซิงก์: ใช้ให้บริการบทเรียนและตรวจปัญหาการทำงาน

ข้อมูล Google Drive และ OAuth

เมื่อผู้ดูแลอนุญาต ระบบใช้ Drive API เพื่ออ่านชื่อ รหัส โครงสร้างโฟลเดอร์ รายการไฟล์ ชนิดไฟล์ เวลาสร้าง/แก้ไข รุ่นไฟล์ ข้อมูลระยะเวลาวิดีโอ และสิทธิ์แชร์ รวมทั้งสร้างโฟลเดอร์ Situation และกิจกรรมในโฟลเดอร์ที่กำหนด ระบบเก็บรหัสไฟล์ รหัสโฟลเดอร์ ลิงก์วิดีโอ ข้อมูลรุ่น และผลซิงก์ไว้ใน Supabase เพื่อจับคู่เนื้อหากับผู้เรียน

การอนุญาตปัจจุบันใช้ scope https://www.googleapis.com/auth/drive ซึ่งให้สิทธิ์กว้างในการดูและจัดการไฟล์ที่บัญชีเข้าถึงได้ ไม่ได้ถูกจำกัดโดย Google ให้เข้าถึงเพียงโฟลเดอร์เดียว ตัวงานซิงก์ของ Only Me Learn จำกัดการจัดเนื้อหาไว้ในโฟลเดอร์หลักที่ตั้งค่าและโฟลเดอร์ลูกค้าภายในนั้น

Refresh Token และข้อมูลลับสำหรับเชื่อมต่อเก็บฝั่งเซิร์ฟเวอร์ ผู้เรียนไม่ได้รับ Token เหล่านี้ ระบบอัตโนมัติไม่เปิดสิทธิ์สาธารณะให้ไฟล์จริงเอง วิดีโอที่ผู้ดูแลแชร์แบบทุกคนที่มีลิงก์อาจเปิดได้โดยผู้ที่มีลิงก์นอกแอปด้วย

การแสดงผลและผู้ให้บริการ

ผู้ดูแลเข้าถึงข้อมูลเพื่อจัดบทเรียนและแก้ปัญหา ผู้เรียนเข้าถึงเนื้อหาที่เผยแพร่ให้ตน Supabase ประมวลผลบัญชี บทเรียน session และงานซิงก์ Airtable เป็นแหล่งข้อมูลผู้เรียน Google Drive จัดเก็บและส่งวิดีโอ ส่วนผู้ให้บริการโฮสต์แอปรับคำขอเว็บ หน้าเอกสารนี้โฮสต์บน GitHub Pages

เมื่อเปิดตัวเล่น Drive เบราว์เซอร์ส่งคำขอถึง Google ซึ่งอาจได้รับ IP address ข้อมูลอุปกรณ์ และคุกกี้ตามการตั้งค่าของผู้ใช้ ผู้ให้บริการแต่ละรายอาจประมวลผลข้อมูลและบันทึกทางเทคนิคในประเทศอื่นตามนโยบายของตน

เสียงและการประเมิน

เสียงที่อัดผ่านไมค์ในรุ่นปัจจุบันอยู่ในหน้านั้นเพื่อเล่นทบทวน ไม่อัปโหลดไปบริการประเมินเสียงภายนอก เสียงอ่านคำศัพท์และประโยคใช้กลไกเสียงของเบราว์เซอร์หรืออุปกรณ์ ซึ่งอาจทำงานผ่านบริการของผู้ผลิตอุปกรณ์ตามการตั้งค่า ผลประเมินที่ระบุว่าเป็นตัวอย่างไม่ใช่การวิเคราะห์เสียงจริง

การใช้ข้อมูลอย่างจำกัด

ข้อมูลที่ได้รับจาก Google ใช้เพื่อจัดและแสดงบทเรียนตามที่อธิบายไว้ ไม่ใช้เพื่อโฆษณา ไม่ขายข้อมูล และไม่ใช้ฝึกโมเดล AI ทั่วไป การเข้าถึงโดยบุคลากรจำกัดตามงานที่ได้รับอนุญาต การสนับสนุน ความปลอดภัย หรือหน้าที่ตามกฎหมาย การใช้และส่งต่อข้อมูลจาก Google อยู่ภายใต้ Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

การเก็บรักษาและการลบ

ข้อมูลบัญชี เนื้อหา และประวัติซิงก์ถูกเก็บเพื่อให้บริการและตรวจปัญหา การสิ้นสุดคอร์สระงับการเข้าเรียน แต่ไม่ได้ลบข้อมูลหรือไฟล์ Drive อัตโนมัติ ติดต่อผู้ดูแลเพื่อขอเข้าถึง แก้ไข หรือลบข้อมูล ผู้ดูแลจะตรวจสอบคำขอและดำเนินการตามที่เกี่ยวข้อง รวมถึงข้อจำกัดด้านบันทึก สำรองข้อมูล และหน้าที่ตามกฎหมาย การลบบัญชีแอปไม่ได้ลบไฟล์ต้นฉบับใน Drive โดยอัตโนมัติ

การถอนสิทธิ์และความปลอดภัย

ผู้ดูแลถอนสิทธิ์เชื่อม Google ได้ที่ การเชื่อมต่อบัญชี Google การถอนสิทธิ์หยุดการเชื่อมครั้งถัดไป แต่ไม่ลบข้อมูลที่บันทึกไว้ก่อนหน้า หากต้องการลบข้อมูลหรือ Token ที่เก็บไว้ ให้ติดต่อผู้ดูแลบริการ

แอปใช้ HTTPS และตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ การเข้าเรียนด้วยเบอร์โทรเพียงอย่างเดียวไม่พิสูจน์ผู้เป็นเจ้าของเบอร์ จึงไม่ควรใช้แอปเก็บข้อมูลอ่อนไหวหรือเนื้อหาลับ

การเปลี่ยนแปลง

เมื่อวิธีใช้ข้อมูลเปลี่ยน จะปรับปรุงนโยบายและวันที่มีผล หากเป็นการใช้ข้อมูล Google นอกเหนือจากที่อนุญาตไว้ จะขอความยินยอมก่อนใช้งานในวัตถุประสงค์ใหม่นั้น
